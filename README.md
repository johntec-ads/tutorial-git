# Tutorial Git Completo

Um tutorial abrangente e amigável sobre Git, GitHub e VS Code, focado em gerenciamento de branches via terminal. Desenvolvido com design colorido e intuitivo para facilitar o aprendizado, mesmo para iniciantes.

## Funcionalidades

- **🎨 Design Amigável**: Cores vibrantes, emojis e animações divertidas para engajar o aprendizado
- **📚 Tutorial Interativo**: Aprenda Git passo a passo com exemplos práticos e visuais
- **🔍 Busca em Tempo Real**: Encontre conteúdo rapidamente
- **🎯 Exercícios Práticos**: Teste seus conhecimentos com exercícios interativos
- **🖥️ Simulador de Terminal**: Pratique comandos Git em um ambiente simulado e colorido
- **🔗 Integração com GitHub**: Explore repositórios reais
- **🌙 Modo Escuro/Claro**: Alternância de tema para melhor experiência
- **📱 PWA**: Funciona offline como Progressive Web App
- **📱 Responsivo**: Otimizado para desktop e mobile

## Design e UX

- **Cores Alegres**: Azul, verde, amarelo e rosa para criar ambiente acolhedor
- **Emojis Contextuais**: Ícones em títulos e elementos para melhor identificação visual
- **Animações Suaves**: Fade-in, bounce e hover effects para interatividade
- **Gradientes Modernos**: Fundos e bordas com gradientes suaves
- **Elementos Visuais**: Bordas arredondadas, sombras e destaques para guiar a atenção

## Estrutura do Projeto

- `index.html`: Página principal com tutorial básico
- `git-*.html`: Páginas específicas para tópicos avançados (Rebase, Cherry-pick, Tags, Stash, Bisect)
- `script.js`: Funcionalidades JavaScript principais
- `search.js`: Sistema de busca
- `exercises.js`: Sistema de exercícios
- `pwa.js`: Service Worker para PWA
- `styles.css`: Estilos principais
- `responsive.css`: Estilos responsivos
- `timeline.css`: Estilos da timeline de progresso

## Melhorias Implementadas

### UI/UX
- Animações suaves de fade-in
- Hover effects nos exercícios
- Tema escuro/claro persistente
- Navegação responsiva com menu hambúrguer
- Acessibilidade com ARIA labels

### Front-end
- Simulador de terminal Git interativo
- Busca em tempo real com debounce
- Sistema de exercícios com progresso salvo
- Integração com GitHub API para exemplos reais

### Back-end
- Como projeto estático, integrado com APIs externas (GitHub API)
- PWA com service worker para cache offline
- Deploy automatizado no Netlify

### Novos Conteúdos
- Página sobre Git Bisect
- Exemplos práticos expandidos
- Recursos adicionais de segurança

## Como Executar

1. Clone o repositório
2. Abra `index.html` no navegador ou use um servidor local:
   ```bash
   npx serve .
   ```
3. Navegue pelas seções e pratique os comandos

## Tecnologias

- HTML5
- CSS3 (com variáveis CSS)
- JavaScript ES6+
- PWA (Service Worker)
- GitHub API
